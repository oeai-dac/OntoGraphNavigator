# Changelog

## 1.0.0 — 2026-10-19

The first complete version. In short (the README tells the whole):

- **Enter and edit** a project of OntoCartographer Studio: forms from the
  mapping, identifier rules, thesauri, the tables; a journal with undo/redo,
  change log and auto-save; the whole project as one `.ognproj` (project file,
  settings, protocols, vocabularies, change history); exports for the Studio,
  the GraphExplorer, RDF, tables.
- **The GraphExplorer's views** over the data being edited — Explorer, Graph,
  Matrix, Map, 3D, Timeline, Charts, Dashboard — with editing in place, in the
  project's languages; the entry form as a pane of the Dashboard.
- **The Harris matrix**, taking over the Harris Matrix Editor's work: relations
  of every kind, phases, objects and groups, unit types, checks, positions
  kept; GraphML in and out; HME files opened directly; a new matrix from a lean
  English template.
- **Recording protocols** as packages bound to any mapping (such as the BDA
  SE-Protokolle), filled-in PDFs.
- **QGIS and Blender** through the GraphExplorer's plugins, with geometries,
  values and new records written back from QGIS.

Next (1.1): exchange formats — an SVG of the matrix, GeoJSON as a file, SE protocol
records as JSON, RDF-star.
